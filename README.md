# agy in chrome

読み方は「antigravity in chrome」です。Chrome のサイドパネルから公式 Antigravity Remote Control のビューを開き、閲覧中のタブから会話用の資料を作れる非公式拡張です。

## 公式ビューを開く

1. Antigravity Desktop で Remote Control を有効にし、Chrome の公式 Web で同じ Google アカウントにログインします。
2. Chrome 157 以降で拡張アイコンを押すと、Google の公式サイトがサイドパネルのメインコンテンツとして開きます。公式画面で端末と会話を選びます。
3. 公式の端末・会話 URL は、資料パネルにある「接続先リンク」に保存できます。

[Google 公式手順](https://antigravity.google/docs/remote-control/)

## 別の Google アカウントでサイドパネルを開く

公式の Google アカウントメニューで切り替え先を選びます。開いた公式 Remote Control の通常タブで右クリックし、「このアカウントでサイドパネルを開く」を選びます。期限切れのアカウントは Google の画面で再認証してください。

切り替えると、拡張が固定した会話と用意したページ資料を解除し、処理中の添付も取り消します。切り替える前に未送信の文章を控えてください。選択した公式ページの URL は同じ Chrome プロファイルの各ウィンドウで、ブラウザを閉じるまで使用します。

## 公式マイクを使う

公式 Remote Control の入力欄にあるマイクを押します。サイドパネルで Chrome の許可画面が出ない場合は、同じ接続先を同じ Chrome プロファイルの通常タブで開き、公式マイクから許可を求めます。許可後、サイドパネルでマイクを押し直してください。

マイク横の状態案内は「ワンタッチ連携の設定・診断」で公式画面への連携を許可すると表示できます。録音と下書きへの反映は公式画面が処理します。[Chrome のマイク設定](https://support.google.com/chrome/answer/2693767?hl=ja)

## Chrome タブに公式会話を固定する

会話一覧・検索の隣のタブ形アイコンを押すと固定状態をアイコンの塗りと背景色で表示します。ホバーまたはキーボードでフォーカスすると説明が出ます。会話をまだ開いていない場合は接続先を固定し、その後に開いた会話を記憶します。別のタブから戻ると固定先が開きます。同じ Web ページを開いた別タブには別の会話を固定できます。

アイコンをもう一度押すと固定を解除します。切り替えで内容を失わないよう、未送信の下書きや添付がある間は固定と解除を保留します。固定はタブを閉じるか Chrome を終了すると解除されます。

## Add context からページ資料を渡す

1. 拡張アイコンを右クリックして「ワンタッチ連携の設定・診断」を選び、設定タブで Chrome の許可を確認します。公式パネルに反映するには、「接続先・資料プレビュー」を一度開いてから公式パネルに戻ります。
2. 公式会話の Add context で「現在の Chrome ページを添付」を選びます。初めてのサイトでは設定タブが開きます。許可した後は、そのタブを閉じて元のページへ戻り、再度項目を選びます。
3. 公式の添付表示が出ない場合は会話欄を見直してください。本文を貼り付ける場合は Add context の「現在の Chrome ページを下書きに挿入」を選びます。
4. ページ側から操作する場合は、ページの右クリックメニューで本文または表示範囲の画像を用意し、そのウィンドウの Add context で選びます。画像には表示範囲全体が含まれます。

複数のサイトで添付する場合は、初回設定または初めて本文の許可を求められた画面で「全 HTTP・HTTPS サイトを許可」を任意で選べます。許可後は各サイトの承認を省略できます。読み取りは Add Context や右クリックから資料を指定したときに行います。サイトごとの許可も選べます。

ページ資料には取得時点の本文 Markdown、元ページ URL、記事本文に残った画像へのリンクを含めます。拡張による画像の再取得はありません。

本試作は公式の添付入力が見つかる場合に限ってファイル添付を試行します。メッセージは公式画面から送信できます。MCP のローカル試作は [検証手順](experiments/mcp-context/README.md) を参照してください。

## ページ資料を会話に使う

共有元のページを右クリックし、「選択範囲とページ情報を Antigravity 用にコピー」または「表示中のページ資料を Antigravity 用にコピー」を選びます。コピーが成功すると拡張アイコンに ✓ が出ます。サイドパネルで開いている公式会話の入力欄に貼り付けてください。

ファイルとして添付する場合は、共有元を右クリックして「ページ資料を Antigravity 添付用ファイルに保存」を選び、公式パネルで「Add context → Files」を開いて `antigravity-page-context.md` を選びます。

送る前に資料を編集したい場合は、拡張アイコンを右クリックし、「接続先・資料プレビュー」を選びます。公式画面から資料プレビューに切り替えると、サイドパネルが読み直されます。

## 開発版を読み込む

Chrome の拡張機能管理画面で、デベロッパー モードを有効にします。「パッケージ化されていない拡張機能を読み込む」で、リポジトリのルートか配布 ZIP の展開先を選びます。更新時は公式ビューを閉じ、対象の拡張カードで再読み込みします。

配布版と公開手順は [GitHub Releases](https://github.com/kamihicouki/agy-in-chrome/releases) と [Chrome Web Store 公開手順](docs/store-release.md) を参照してください。

隔離ブラウザでの開発検証では Playwright の Chromium を使います。`node --test tests/*.test.mjs tests/*.browser.mjs experiments/mcp-context/server.test.mjs` を実行します。

公式画面に追加する UI の方針と検証条件は [デザイン定義](docs/design.md) を参照してください。
