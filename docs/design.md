# agy in chrome のデザイン定義

## 公式画面を基準にする

- Antigravity と Antigravity Remote Control の同じ用途の部品を見比べ、Chrome サイドパネルに表示される公式 Remote Control の現行画面を最終基準にする。
- 公式の入力欄、メニューの位置、操作順、公式項目の文言を尊重する。操作を追加するときは、その用途の既存メニューの末尾にまとめる。
- 拡張の操作には「agy in chrome」の区切り見出しを付ける。ライト・ダークのどちらでも文字で出所を確認できるようにする。

## Add Context

- 公式項目の文字、前景色、行の高さ、左右の余白、アイコンの寸法を参考にする。拡張項目内のアイコンは、前景色と同じ色の線で揃える。
- セクションの境界は細い区切り線と控えめな見出しで示す。公式メニュー側の背景を使い、狭い幅では長いラベルを折り返す。
- 拡張が追加する要素の内側にスタイルを限定する。公式の要素、クラス、イベントハンドラーを複製・変更しない。読み取った公式の見た目を使い、取得できる情報が少ない場合は継承と CSS の既定値で表示する。
- マウスのハイライトとキーボードのフォーカスを見分けられるようにする。公式項目から矢印キーで移動でき、Enter で実行できるようにする。Escape は公式側の閉じる操作に渡す。

## 変更時の確認

- 公式項目と拡張項目を同じメニュー内で見比べる。ライトとダーク、通常幅と狭いサイドパネルで、文字・アイコン・余白の揃いと折り返しを確認する。
- 矢印キー、Enter、Escape を確認し、公式項目の操作、既存の下書き、入力欄の表示に影響がないことを確かめる。
- 隔離 Chrome の模擬画面と、ログイン済み Remote Control での実機確認を区別して記録する。
